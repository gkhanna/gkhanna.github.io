# Gaurav Khanna GitHub Pages site

Initial personal academic website for Gaurav Khanna, published through GitHub Pages at:

https://gkhanna.github.io/

## Structure

- `index.html` - single-page site
- `styles.css` - responsive visual design
- `script.js` - navigation and publication filtering

## Source material

The first draft uses public information from URI Physics, URI Gravity Research, URI IACR/Rhody Today, Wikipedia, Google Scholar, arXiv, INSPIRE, and public media articles. The site includes a visible sources section so the draft can be reviewed and refined later.

## Notes

This is an experimental starting point, not a final official biography.
